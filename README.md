# AI-Lab-Line2
AI-Lab-Line2 关于专业软件GUIAgent的学习研究平台

大家好，很高兴大家加入我们line2方向，我们致力于专业GUI软件的自动化研究，目前已经完成一篇论文的投稿，以及省级大创立项，也拿到过多项全国奖项与省级奖项，未来将要致力于GUI软件训练数据的处理组织以及小模型的强化学习方向，相信在大家的加入与合作下我们会取得更好的成果，也可以保证大家会度过一段充实的时光，下面是我对line2同学的一些小要求和一些建议：长期主义与活在当下。

我想和大家讲的第一件事是什么是长期主义，为什么我们要坚持长期主义。长期主义，是在无法立刻看到结果的情况下，仍然围绕一个长期有价值的方向，持续做那些能够积累、能够复利、并且不会轻易被短期波动推翻的事情。这是一件很重要的事情，几乎人生中所有重大的成功都需要一段想得开，坐得住，挺下去的时间的淬炼，只有我们明白并且理解长期主义我们才能在对的有价值的方向上一致坚持下去。

首先长期主义不等于坚持，我们很容易赞美一个坚持了很多年的人。一个人做了一件事五年、十年，我们本能地认为这是一件值得敬佩的事情。但如果仔细想一想，“坚持时间很长”本身并不能证明这个选择是正确的。有人可能在一个已经没有发展空间的方向上投入了很多年，只因为过去已经投入了太多，不愿意承认自己需要改变。有人可能做着一份越来越不适合自己的工作，却不断告诉自己：“再坚持一下。”有人可能研究一个已经被事实不断否定的问题，但因为舍不得过去的投入，所以继续追加时间。这种行为在表面上也非常“长期”。但它并不是长期主义，而是沉没成本。所以真正的长期主义必须同时具备两个看起来矛盾的能力：**对方向有耐心，对路径保持灵活。**所谓方向，是你真正想积累的东西。比如你想成为一个真正理解agent系统的人，比如你想成为一个专业的工程师，这可以是方向。你选择某个模型、某个框架、某一种实验方式，这只是路径。路径失败了，可以换的。我们要坚持的是长远的规划和目标，而不是在自己的舒适圈每天跑10圈。

在有了明确方向的情况下，我们就真正走进了长期主义，在这之后就会发现他的精髓————复利。为什么一件事情值得长期做？一个很核心的原因，是它能够产生复利。复利这个词最早让人想到的是钱。本金产生利息，利息重新进入本金，之后产生更多利息。时间越长，增长越不是线性的。但人生中大量真正重要的东西都具有类似结构。知识会复利。技能会复利。判断力会复利。声誉会复利。关系会复利。作品会复利。甚至一个人对世界的理解，也会复利。以我为例我刚进入一个领域的人，读十篇论文，可能还是非常模糊。再读五十篇，开始能分辨不同研究路线。读到一百篇以后，开始知道哪些问题重要，哪些问题只是包装得漂亮。继续做实验、写代码、投稿、被拒、修改、复现别人的工作之后，我逐渐不再只是“知道一些论文”，而是形成了一套内部结构。这时候再看到一篇新的论文，我获取的信息量和新人已经完全不同。新的知识不再孤立进入，而是迅速连接到已有结构中，这就是知识复利。时间很残酷但是长期主义的复利会让时间成为我们最忠实的朋友。

长期主义的内容和大家聊过了，既然他这么有用为什么坚持下来的人很少呢？第一它需要准确的判断力，判断你的远景目标是否符合时代大势。第二就是坚持，怎么坚持下去。第一条相信大家在line2的学习和与我们的交流中会得到答案。我们今天和大家谈谈第二个问题，怎么坚持。

这就要引出第二个关键词了————活在当下。我曾经在求学过程中问过我的老师，学长：这么多事情，这么远大的目标，您是怎么完成的。同样的话从不同的人口中出现了三次：做好眼前的每一件事情。这就是我想和大家说的：活在当下，踏上取经路，比抵达灵山更重要。脚踏实地，万象更新，我们先谈完成再论完美。当然活在当下还有另外的意义，长期主义最大的困难在于延迟反馈，这和强化学习目前遇到的困难很像，那么我们即使开始做了，投入当下了但是还是很难熬怎么办？我的建议是：不要去赶路，去感受路，去生活而不是简单活着。记住你所热爱的就是你的生活，长期主义只是生活的一部分，而不是全部。究竟是多美好的未来才能让我们忘记眼下的四季？我想是没有这种未来值得的。当然当你投入当下的生活和长期的规划时，你身边自然就会聚集一批有理想有情趣懂生活的人，大家一起培养兴趣，享受生活，我想这也是我们的初衷和理想！

最后，感谢大家看完，也欢迎大家加入line2，人这一生会遇到很多颜色的人，黑色的，白色的，红色的，但总有一天你会遇到一些闪闪发光的人，希望我们都是彼此大学中最美的底色！
